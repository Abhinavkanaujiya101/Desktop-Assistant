## 🚀 About the Project

**Desktop Assistant** is a lightweight personal assistant that lives on your computer and performs everyday tasks with simple commands.

No more clicking through menus or typing the same searches again and again. Just tell it what you need, and it gets it done. ⚡

---

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🗣️ | **Command Interaction** | Give instructions by voice or text |
| 🌐 | **Web Search & Browsing** | Open websites and search instantly |
| 📂 | **App Launcher** | Launch apps and system tools with one command |
| 🕒 | **Time & Date** | Get the current time and date on demand |
| 🔊 | **Voice Feedback** | The assistant talks back to you |

## ⚙️ Getting Started

### 📋 Prerequisites

- Python 3.8 or higher
- A working microphone (for voice commands)

### 📥 Installation

```bash
# 1. Clone the repository
git clone https://github.com/Abhinavkanaujiya101/Desktop-Assistant.git

# 2. Go into the project folder
cd Desktop-Assistant/"Once More"

# 3. Install dependencies
pip install -r requirements.txt
```

### ▶️ Run it

```bash
python main.py
```
